# SnapMark 0.2.0 — Screen recording and video editing

- Adds a Screen Recording mode alongside the existing screenshot workflow.
- Implements Wayland ScreenCast/PipeWire monitor/window capture and X11
  full-display/region capture, countdown, recording indicator, pause/resume and
  optional explicitly selected microphone/system-monitor audio.
- Adds Qt Multimedia playback, timeline scrubbing, playback speeds and volume.
- Adds non-destructive trim, split/remove, crop and undo/redo.
- Adds timed highlighter, pen, arrow, shape, text and static blur/pixelation tools.
- Exports edited H.264/AAC MP4 with worker progress/cancellation, safe separate
  output files and source preservation. Saves editable versioned JSON projects.
- Bundles Qt Multimedia and declares Ubuntu FFmpeg/GStreamer/GI dependencies.

The package targets Ubuntu 25.10 amd64/glibc 2.42, matching its build host.

Synthetic capture/pause/audio, real FFmpeg export and Qt playback were checked;
live Wayland source selection timed out without a selection. X11 desktop capture,
real audio synchronization, multi-monitor/high-DPI, long recordings and installed
package operation still need the [manual release checks](../video.md).
Wayland region capture uses monitor recording followed by editor cropping.
This is a development update, not a claim of verified compatibility on every
Ubuntu configuration. Source recordings remain local and are never auto-uploaded.
