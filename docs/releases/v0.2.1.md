# SnapMark 0.2.1 — Native capture and video workspace fixes

- Keep Print Screen on Ubuntu’s native screenshot/recording chooser with system
  defaults; migrate old SnapMark shortcut overrides back to their saved bindings.
- Import completed native recordings while SnapMark is open, using Linux
  close-write/atomic-move notifications rather than opening still-growing files.
- Default in-app recording to Select area. On Wayland, choose a monitor once,
  select a native-pixel rectangle from its authorized preview, then capture only
  that rectangle. Audio and the recording timer start after area selection.
- Replace the video editor’s crowded controls with a left icon rail, tool-specific
  cursors and contextual properties, icon project actions and an Outline-only
  right panel. Make left, right and bottom panels resizable/movable docks.
- Give each annotation a timeline row: move/resize timing by dragging bars and
  edges, and reorder overlays by dragging their row names. All changes support
  undo/redo, editable project persistence and exported output.
- Keep source video preserved and existing screenshot tools available.

Build targets Ubuntu 25.10 amd64. Synthetic pipeline and UI tests do not replace
manual Wayland/X11, audio, high-DPI or long-recording checks; see docs/video.md.
