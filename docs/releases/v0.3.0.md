# SnapMark 0.3.0

Add video animation editing with 41 annotation entrance, emphasis and exit
presets, contextual effect properties, advanced timing/repeat controls and an
embedded live preview. Apply edits with undo/redo and retain them in version-2
projects; existing version-1 projects remain readable.

Animate the whole video's opening and ending from IN/OUT timeline markers.
Join badges configure five transitions through a chosen color, with optional
audio fades, while preserving sequence duration. Animated MP4 exports share the
preview compositor and process frames incrementally with cancellation support.

See [the animation guide](../animations.md) for applicability and timing details.
Privacy blur/pixelation regions remain static. Animated high-resolution exports
can take longer; long-video performance and live desktop capture/installation
still need manual verification.

The bundled installer targets Ubuntu 25.10 amd64 (glibc 2.42+). No system-wide
installation is performed by the build or automated checks.

Validation: 183 automated tests passed, including real FFmpeg export checks.
A live Qt playback check verified opening, join, animated-layer and ending
effects on reordered synthetic footage.
