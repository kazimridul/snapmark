SnapMark is a local screenshot and annotation app for Ubuntu. Capture a screen or region, add arrows, text, and highlights, crop or obscure details, then save or copy the result.

### Download

- **snapmark_0.1.3_amd64.deb** — installer for **Ubuntu 25.10, x86-64 (amd64)**.
- **snapmark_0.1.3_amd64.deb.sha256** — SHA-256 checksum.

Python, Qt, and application dependencies are bundled. This binary requires glibc 2.42 or newer and does **not** support Ubuntu 24.04 or 22.04. The source can be installed separately on supported Python/Qt environments; GitHub's source archives are not installers.

### Install and run

Download both files into the same directory, open a terminal there, and run:

```bash
sha256sum -c snapmark_0.1.3_amd64.deb.sha256
sudo apt install ./snapmark_0.1.3_amd64.deb
snapmark
```

You can also open **SnapMark** from the applications menu.

### Changes

- Added a bundled Ubuntu installer, desktop launcher, icon, and SHA-256 checksum.
- Enabled Window capture through the system screenshot chooser on Wayland portal v2. Click **Select Window**, choose **Window** in the system UI, then select the desired window.
- Fixed Launch at login for the bundled executable.

### Validation and limitations

67 automated tests pass. The extracted installer executable reports the correct version and passes an offscreen GUI launch smoke test. Apt dependency resolution was checked in simulation on Ubuntu 25.10. Real desktop installation, screenshot permission dialogs, clipboard sharing, and multiple displays still require manual verification. This release is unsigned.

Wayland capture uses the desktop portal and may show its permission or screenshot UI. Direct active-window capture depends on desktop support. Blur and pixelation are visual effects; cover sensitive information with an opaque rectangle when needed.

### Uninstall

Disable **Launch at login** in Settings if enabled, then run:

```bash
sudo apt remove snapmark
```

Saved images and user settings are preserved.
