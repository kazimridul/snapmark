# SnapMark 0.2.3 — Capture permissions, saving feedback and editor fixes

- Keep the requesting Wayland window focused and request the interactive desktop
  screenshot flow, addressing GNOME's focused-app access-dialog denial.
- Save new screenshots before opening their editor. Unchanged saved captures and
  recordings close without an unsaved warning; undo to the saved state is clean.
- Show a recording-saving loader through finalization and MP4 encoding progress.
- Hide finished export progress and show a simple “Export complete” message.
- Add a dedicated video crop workspace with handles, aspect presets, pixel
  geometry and Apply/Cancel controls.
- Fix object move gestures, add a live selection outline and direct geometry
  editing, and prevent no-op/rounded property values from dirtying a project.
- Add file properties, Open folder and confirmed storage deletion for both media
  types, including source-video deletion from its editor.

The source-recording and export safety rules remain in place. Desktop screenshot
permission approval still needs a real retest; the diagnostic window timed out
without a capture request. See docs/video.md for verification and limitations.
