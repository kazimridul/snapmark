SnapMark 0.1.4 improves image opening and adds Print Screen integration on Ubuntu GNOME.

### Changes

- Opening an image from the file manager or `snapmark /path/to/image.png` shows only the editor. Closing the last editor exits that process.
- Launching SnapMark normally from the applications menu or terminal opens the main window as before.
- On the first normal launch, Ubuntu GNOME's Print Screen key is registered to start SnapMark region capture. Screenshot commands keep the main window hidden.
- Settings → General → **Use SnapMark for Print Screen (GNOME)** can restore the previous key binding. Modified screenshot shortcuts and unrelated custom shortcuts are preserved. Disable this option before uninstalling.
- Fixed failed and cancelled standalone launches so they do not leave an invisible process running.

### Install

Download the `.deb` and matching `.sha256` file into the same directory:

```bash
sha256sum -c snapmark_0.1.4_amd64.deb.sha256
sudo apt install ./snapmark_0.1.4_amd64.deb
snapmark
```

The bundled installer targets **Ubuntu 25.10 x86-64 (amd64)** and requires glibc 2.42 or newer. It does not support Ubuntu 24.04 or 22.04. Python and Qt are included. Launch SnapMark normally once after installation to register Print Screen. Wayland may still show the desktop screenshot chooser or permission prompt.

### Verification

74 automated tests pass, including standalone editor lifecycle, missing-file handling, Print Screen registration, rollback, restore, and preservation of user-modified shortcuts. Actual desktop key delivery, screenshot permissions, installed application launch, and multiple displays still require manual verification. This package is unsigned.

### Uninstall

Disable **Use SnapMark for Print Screen** and **Launch at login** in Settings first, then run `sudo apt remove snapmark`. Saved images and user settings are preserved.
